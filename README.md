# House Price Prediction with Machine Learning

Predict the **next month's city-level median home price** from historical monthly housing prices using Scikit-learn's Linear Regression. This is a time-series forecasting project using the `txhousing.csv` dataset, **not** a model for predicting the sale price of an individual house.

## Project overview

The project covers data exploration, missing-value handling, chronological feature engineering, model selection using a validation period, comparison with a simple baseline, and final evaluation on a held-out test period. It includes separate scripts for training and making predictions with a saved model.

### Input features

| Feature | Meaning |
| --- | --- |
| `median` | Median price in the current month |
| `median_lag1` | Median price one calendar month earlier |
| `median_lag2` | Median price two calendar months earlier |
| `median_ma6` | Average of median prices across the current month and previous five months |

All six months used for feature construction must be **consecutive months for the same city**. Predictions are made after the current month's median is available.

## Installation

1. Clone or download the project and open a terminal in its directory.
2. Make sure Python and pip are installed.
3. Optionally create and activate a virtual environment.
4. Install the project dependencies:

```bash
python -m pip install -r requirements.txt
```

The dependencies are `pandas`, `numpy`, `scikit-learn`, `matplotlib`, and `joblib`.

## Dataset

Place `txhousing.csv` in the same directory as `train.py` before training. The script expects at least the following columns: `city`, `year`, `month`, and `median`.

The dataset and its redistribution rights should be checked before publishing the CSV to a public repository. If the CSV is not included on GitHub, users must obtain it separately and place it in the project folder.

## Train the model

```bash
python train.py
```

The training script:

1. Sorts observations by city, year, and month.
2. Creates the next-month target with a city-wise shift.
3. Builds one-month and two-month lag features plus a six-month rolling average.
4. Removes observations with missing required values or nonconsecutive months.
5. Trains a four-feature Linear Regression model using observations with **target dates before January 2014**.
6. Evaluates predictions on observations with **target dates from January 2014 onward**.
7. Saves the fitted model to `house_price_model.joblib`.

The prepared dataset contains **7,560 valid observations**: **6,698** in the final training portion (including the earlier validation period) and **862** in the test portion.

## Make a prediction

After generating `house_price_model.joblib`, run:

```bash
python predict.py
```

The example in `predict.py` uses six median prices ordered **oldest to newest**:

```python
prices = [110000, 112000, 115000, 118000, 121000, 125000]
```

For this illustrative example, the trained model returned a next-month median price of approximately **$120,771.60**.

The script calculates the four features, creates a DataFrame using the training feature names and order, loads the saved model, and calls `.predict()`.

The input checks currently require exactly six positive, finite numerical values. **City identity and calendar-month continuity are assumptions, not automatically verified by `predict.py`**; callers must provide six consecutive months from the same city.

## Model selection and evaluation

During development, models with different feature sets were compared on a separate chronological validation period. The selected approach was Linear Regression using the four features above. Adding one-hot-encoded city indicators did not improve validation MAE.

After choosing the model, it was retrained using the original training **and validation** observations, leaving the test observations out of fitting.

### Final held-out test results

| Metric | Linear Regression | Persistence baseline |
| --- | ---: | ---: |
| Mean Absolute Error (MAE) | **$9,787.97** | $11,564.73 |
| Root Mean Squared Error (RMSE) | **$13,230.07** | $16,456.49 |
| R² | **0.9157** | Not calculated |

The persistence baseline predicts that next month's median price will equal the current month's median price. The selected model achieved approximately **15.4% lower test MAE** than that baseline.

These are results on this historical dataset and test period, not guarantees of future performance. The held-out test data should not be repeatedly used for further model selection.

## Limitations

- **City-level forecasts:** Predicts each city's monthly median price, not prices of individual properties.
- **Availability:** Requires six consecutive months of historical median prices from one city; the latest month must already be known.
- **Input integrity:** Current prediction input validation checks length and numerical validity, but does not verify city labels or dates.
- **Historical performance:** Real estate conditions change over time; results may differ in newer periods or previously unseen markets.
- **Model simplicity:** Linear Regression captures linear relationships using these features, but not every driver of housing prices.
- **Dependencies:** Loading a saved Scikit-learn model requires a compatible software environment. Only load `.joblib` files from trusted sources.
